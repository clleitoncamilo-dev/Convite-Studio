# 🎨 Editor de Convites Digitais

Editor interativo para criação de convites personalizados com funcionalidades de arrastar e soltar (drag & drop).

---

## 🚀 Funcionalidades

- Edição de texto em tempo real
- Drag & Drop de elementos
- Upload de imagens
- Redimensionamento de elementos
- Personalização de cores

---

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

---

## 💡 Objetivo

Criar uma ferramenta interativa semelhante a editores como Canva, focada em personalização de convites digitais.
